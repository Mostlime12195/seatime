SeaTime

An experimental time tracker for coding with AI.

Code by hand and your time counts the way that it does on Hackatime. Your time with AI tools counts too. {{if $c.CheckOn}}Each prompt that you send counts for up to {{$c.Most}} minutes, depending on how good it is.{{else}}Each new prompt counts for up to {{$c.Window}} minutes.{{end}} Time that an agent runs on its own does not count.

Get started

  1. Run the installer in a terminal. It opens your browser so that you can sign in with Hack Club.
    macOS / Linux
    curl -fsSL {{.BaseURL}}/install.sh | sh
    Windows
    irm {{.BaseURL}}/install.ps1 | iex
  2. Write some code. Your hours show up here within a few minutes.

Works with

Claude Code, Cursor and Gemini CLI, tested with real installs. Codex CLI, opencode, GitHub Copilot, Windsurf, Antigravity, Kilo Code, Aider, Cline, Roo Code and Amp, built from their documentation. SeaTime finds them on its own.

Your editor too, if it has the WakaTime or Hackatime plugin.

Applications that read your hours

Applications, such as the site of a Hack Club YSWS program, can read your hours from SeaTime the way that they read them from Hackatime. You do not submit anything.

Each application asks for your permission first. You can take it back in Settings.

Privacy

SeaTime sends your hours, the names of your projects, and hashes that nobody can read back. Your commands and file paths stay on your computer.

{{if $c.CheckOn}}

Your code and your prompts stay there too, with one exception. To judge a new prompt, an AI model reads it with the chat and the code changes around it, and with the project's file names and the start of its README. SeaTime does not store any of this, and the provider of the model must not keep it.

{{else}}

Your code and your prompts stay there too.

{{end}}

Questions

Is my code private?

Your code stays on your computer.{{if $c.CheckOn}} To judge a prompt, an AI model also reads the code change after it, the project's file names and the start of its README. SeaTime does not store them.{{end}}

Does it replace Hackatime?

No. If your editor has the WakaTime or Hackatime plugin, its time still goes to Hackatime as before. SeaTime adds your time with AI tools, which never goes to Hackatime.

How do I stop SeaTime?

In Settings, remove SeaTime from a computer. It takes its hooks out of your AI tools and stops there.

Can I delete my data?

Yes. In Settings you can delete your SeaTime account and everything in it. Your computers then remove SeaTime by themselves.

Is it free and open source?

Yes. The code is on GitHub under the AGPLv3.
