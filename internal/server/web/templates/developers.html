Each address must start with https://, or with http://localhost or http://127.0.0.1 while you test. SeaTime sends people back only to an address that matches one of these exactly.

How it works

SeaTime uses OAuth 2.0 with the authorization code flow, and PKCE (S256) is required. There is one scope, read.

  • Send the person to {{.BaseURL}}/oauth/authorize
  • Exchange the code for a token at {{.BaseURL}}/oauth/token
  • Read hours with the access token, for example at {{.BaseURL}}/api/v1/users/current/stats and {{.BaseURL}}/api/v1/users/current/projects/{project}/stats

Every endpoint is listed in YSWS.md in the SeaTime repository.
